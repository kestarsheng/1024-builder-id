# 1024 Builder 身份证

> 输入 GitHub 用户名，把公开数据装订成一张「1024 开发者联合会 · Builder 身份证」——红章、全息贴纸、条码，一个不少。
>
> TRAE 1024 狂欢周作品 · 致敬每一个正在 Build 的人

## 在线体验

https://kestarsheng.github.io/1024-builder-id/

## 它是什么

一张会动、能翻面、可保存 PNG 的电子证件。你的 GitHub 公开数据会换算成各种奇怪的单位：

- **代码年龄**：按 1024 天进制显示（例如 142 天 = 0.14 × 1024）
- **星标资产**：Star 总数换算成键盘台数（÷1024）
- **主要武器**：仓库语言抽样分布（证件背面）
- **称号系统**：Star 收割机 / 十年老 Build 手 / 仓库囤积症患者 / 1024 天幸存者 / 正在 Build 的人……
- **证号**：由用户名 + GitHub ID 哈希生成的唯一编号（`1024-XXXX-XXXX`）

点击证件可翻面查看签发记录；「保存 PNG」由 Canvas 手绘导出 2x 高清图，可直接发回帖传播。

## 设计手记

- **拟物证件 × 复古终端**：证件用仿宋字体还原中文证件手感，页面是深色终端工作台
- 红章、全息贴纸（hue-rotate 动画）、条码、像素猫全部手绘（CSS/SVG/Canvas），零外部图片资源
- 数据实时来自 GitHub 公开 API，无后端、无存储、无登录，刷新即可重新签发
- URL 携带 `?u=用户名`，可直接分享某人的证件链接

## 技术栈

Vue 3 + Vite + 原生 Canvas（PNG 导出）+ GitHub REST API。部署在 GitHub Pages，push 即发布。

## 本地开发

```bash
npm install
npm run dev
```

## 隐私

仅读取公开 API（用户资料 + 公开仓库列表），不请求任何权限，不存储任何数据。
